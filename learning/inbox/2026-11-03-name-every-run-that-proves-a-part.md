When two runs each prove a different part of a scenario, name both in the evidence without asking.

**Why:** the developer was asked whether to record one run or both, and answered that the question was needless: naming every run that proves something only makes the evidence stronger, and a hand-over question about it costs their time.

**How to apply:** at the hand-over, do not put a `q` asking which of several valid runs to cite; cite every run that proves a part of the scenario, and keep the question for choices that change what is built or what is claimed.
