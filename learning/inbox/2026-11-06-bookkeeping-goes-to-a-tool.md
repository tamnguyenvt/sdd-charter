When a playbook asks an agent to keep a record by hand — a time, a running number, a round counted on — the agent guesses, skips or rewrites it from one walk to the next, whatever the prose says; a script of the charter that writes the record keeps it right.

**Why:** on CORE Story 30, ten real walks of /sdd-bug-fix each broke the timeline a different way (times made up, rows merged, rounds restarted) until `specs.mjs row` wrote each row; after it, every walk numbered and timed its rows right.

**How to apply:** when a story asks for a record kept the same way every time, plan a command of the spec set's script to write it, and keep the playbook to when to call it.
